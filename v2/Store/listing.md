## Español (es-es)

**Nombre:** Sync two File

**Descripción corta** (máx. 100 caracteres):
Respaldo automático en tiempo real de tus carpetas a otro disco, con versiones y restauración.

**Descripción:**

Sync two File copia automáticamente tus carpetas a un disco de respaldo (USB, disco externo o segundo disco) en cuanto cambian. Lo configuras una vez y se encarga solo, desde el icono junto al reloj.

- Respaldo en tiempo real: los cambios se copian a los pocos segundos, sin que tengas que hacer nada.
- Papelera de versiones: antes de reemplazar o quitar un archivo del respaldo, la versión anterior se guarda para que puedas recuperarla.
- Restaurar: recupera un solo archivo, una carpeta o todo el respaldo con un par de clics.
- Comprobar respaldo: compara origen y respaldo y te avisa si falta algo o si el disco lleva días sin conectarse.
- Bloqueo de seguridad: cada par de carpetas queda protegido para que no lo borres o cambies por accidente.
- Exclusiones: deja fuera archivos temporales o carpetas que no quieras copiar.
- Historial y actividad: mira qué se copió y cuándo.
- Pausar todo con un clic, inicio con Windows y modo oscuro.
- En español e inglés.

Tus archivos no salen de tu PC: la app no usa internet, no tiene cuentas ni recopila datos.

## English (en-us)

**Name:** Sync two File

**Short description** (max 100 characters):
Real-time automatic backup of your folders to another drive, with versions and restore.

**Description:**

Sync two File automatically copies your folders to a backup drive (USB stick, external disk or a second drive) as soon as they change. Set it up once and it takes care of itself from the icon next to the clock.

- Real-time backup: changes are copied within seconds, with nothing for you to do.
- Versions trash: before a file in the backup is replaced or removed, the previous version is kept so you can get it back.
- Restore: recover a single file, a folder or the whole backup in a couple of clicks.
- Verify backup: compares source and backup and warns you if something is missing or the drive hasn't been connected for days.
- Safety lock: each folder pair is protected so you can't delete or change it by accident.
- Exclusions: leave out temporary files or folders you don't want copied.
- History and activity: see what was copied and when.
- Pause everything with one click, start with Windows and dark theme.
- In English and Spanish.

Your files never leave your PC: the app doesn't use the internet, has no accounts and collects no data.

**Product features** (one per line, max 20):
Real-time automatic backup
Versions trash to recover previous files
Restore a file, a folder or everything
Backup verification and alerts
Safety lock per folder pair
File and folder exclusions
Copy history
Tray icon and pause all
Start with Windows
English and Spanish

**Keywords:** backup, sync, synchronize, folders, external drive, USB, versions, restore, copy

**What's new (2.0):**
Rewritten from scratch: versions trash, backup verification with alerts, history, tray icon, pause all, exclusions, single-file restore, languages and a welcome wizard. Automatically imports your 1.x settings.
